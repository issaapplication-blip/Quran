# المصحف الشريف | Al Mushaf Al Shareef

تطبيق ويب تقدمي (PWA) مستقل بواجهة عربية RTL، صُمم للهواتف والقراءة الهادئة.

## الأقسام والوظائف

- **المصحف:** مصحف المدينة 604 صفحات و30 جزءاً، فهرس 114 سورة، انتقال بالصفحة أو السورة أو الجزء، بحث غير حساس للتشكيل، حفظ آخر موضع، ووضع صفحات أو تمرير مستمر.
- **القراءة:** صفحة بلون ورقي/كريمي أو ليلي، إطار زخرفي هادئ، أرقام الآيات، حجم خط قابل للتعديل، وخيارات الخطوط العربية.
- **الأذكار:** الصباح والمساء، بعد الصلاة، النوم، الاستيقاظ، المسجد، والأدعية؛ مع عدد التكرار، تقدم الورد، ومصدر الذكر.
- **السبحة:** أذكار جاهزة أو مخصصة، هدف 33/100/1000 أو هدف يحدده المستخدم، تراجع، تصفير، اهتزاز اختياري، وإحصاء يومي وإجمالي.
- **القبلة والصلاة:** واجهتان قيد التجهيز. لا تعرضان مواقيت أو اتجاهات تقديرية ولا تطلبان موقع الهاتف في هذه النسخة.

## الخطوط

تفضّل الواجهة عائلتي Amiri Quran/Amiri للنص القرآني وTajawal للواجهة من الخطوط المثبتة محلياً على الجهاز، ثم تستخدم بدائل عربية محلية. لم يتم تضمين ملفات خطوط مرخصة داخل هذا الفرع بعد، ولا توجد أي طلبات Google Fonts أو CDN؛ لذلك قد يختلف شكل الخط بحسب الخطوط المتاحة على الجهاز.

## الفحص والبناء

يتطلب الفحص Node.js:
- \`npm run check\` لفحص صياغة ملفات JavaScript وعامل الخدمة.
- \`npm install\` ثم \`npm run build\` لاستخدام esbuild كأداة تطوير فقط. لا توجد مكتبات تشغيل.

## مصادر البيانات

- النص القرآني: Tanzil Uthmani v1.1؛ محفوظ كما هو دون تطبيع أو حذف أو تعديل. راجع \`data/TANZIL-NOTICE.txt\`.
- حدود صفحات المصحف: خريطة 604 صفحة و30 جزءاً في \`data/mushaf-pages.json\`.
- الأذكار: Seen-Arabic/Morning-And-Evening-Adhkar-DB مع مراجع المصدر كما وردت في البيانات، وإضافات مختارة موثقة في \`data/ADHKAR-SOURCE.txt\`.

## الخصوصية

المشروع مستقل عن RAFIQ ولا يتصل بمشروع Supabase أو أي خادم مستخدم. البحث والإعدادات ومواضع القراءة وتقدم الأذكار والسبحة تحفظ محلياً في المتصفح.
